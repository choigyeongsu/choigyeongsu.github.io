Privacy Policy

Last updated: October 9, 2026

1. Introduction

Synology Rclone is a personal application that connects Google Drive to a privately managed Synology NAS using Rclone. It is intended for personal use only.

2. Information Accessed

The application uses Google OAuth 2.0 authorization to access Google Drive. Depending on the permissions granted, it may access Drive file names, metadata, folder structures, and file contents. OAuth authorization tokens are also used to maintain the connection.

3. Use of Information

Google Drive data is accessed to mount, browse, and read files on the owner's Synology NAS. The current Rclone mount is configured as read-only.

Google user data is not used for advertising, marketing, or profiling. It is not sold to third parties.

4. Storage and Security

OAuth credentials are stored in the Rclone configuration on the user's NAS. File content and metadata may be cached locally for normal Rclone operation.

Access to these files is controlled through the owner's NAS security settings. No separate application database or cloud storage service is operated.

5. Data Sharing

Google Drive information is used only for the authorized personal integration. It is not intentionally disclosed to advertisers or data brokers. Google processes requests through its own Google Drive API services.

6. Data Retention and Deletion

OAuth credentials and cached data remain on the NAS until removed by its owner or cleaned up by the configured cache management process.

Access can be revoked through Google Account security settings. Local OAuth credentials and cached files can be deleted from the NAS by its owner.

7. Google API Data

The use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.
