Synology Rclone

Personal Google Drive Integration

Synology Rclone is a personal integration using Rclone to access Google Drive from a Synology NAS.

The application uses Google OAuth 2.0 to authorize access to the user's Google Drive account.

Authorized Drive files can be mounted and accessed through the user's Synology NAS.

This application is intended for personal use and is not offered as a public service.
